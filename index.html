Mode dial

4つのモードの違いは「どこまでカメラに任せるか」だけ

どのモードでも写真の明るさの決まり方は同じです。違うのは、4つのダイヤルのうち何本を自分で回すか。P → A → S → M の順に、カメラに任せる範囲が減っていきます。上のダイヤルを回すと、カメラが担当するダイヤルが AUTO になって自動で動きます。

Same brightness

明るさは同じ、写りは違う組み合わせ

絞りを1段開けたら、シャッターを1段速くする。光の量は「絞り × 時間 × 感度」の掛け算なので、片方を増やしてもう片方を同じだけ減らせば、明るさは変わりません。変わるのはボケの量とブレの止まり方だけ。カメラの設定選びは、ここから始まります。
押すと切り替わります。A モードなら絞りを、S モードならシャッターを選んだことになり、残りはカメラが合わせます。P モードではプログラムシフト（明るさそのままで組み合わせだけ変更）になります。

Three dials

3つのダイヤルは、明るさと「もう一つ」を同時に動かす
01 / APERTURE

絞り（F値）

レンズの穴の大きさ

数字が小さいほど穴は大きく、光をたくさん取り込みます。同時にピントの合う奥行きが薄くなり、背景が溶けます。

明るさf/1.4 ← 明るい ／ 暗い → f/16
ボケf/1.4 ← 大きい ／ 全部くっきり → f/16
02 / SHUTTER

シャッター速度

光を受ける時間

長いほど明るくなりますが、その間の動きはすべて写り込みます。速ければ水しぶきも止まり、遅ければ光が線になります。

明るさ1秒 ← 明るい ／ 暗い → 1/4000
ブレ1秒 ← 流れる ／ 止まる → 1/4000
03 / ISO

ISO感度

増幅のつまみ

足りない光を電気的に増幅します。暗い場所の最後の手段。上げるほどザラつき（ノイズ）が増え、色が浅くなります。

明るさISO100 ← 暗い ／ 明るい → ISO25600
画質ISO100 ← きれい ／ ザラつく → ISO25600

露出補正だけは仲間はずれです。これは光を増やすダイヤルではなく、「正解の明るさ」の位置そのものを動かすダイヤル。露出計の「狙い」マークが左右に動くのはそのためです。
P・A・S モードなら、狙いを動かした分だけカメラが担当のダイヤルを回すので、写真が実際に明るく／暗くなります。M モードでは狙いだけが動いて写真は変わりません — 自分で追いかける必要があります。ここが、露出補正がいちばん誤解されるところです。
